# Count Down Timer

A simple and interactive countdown timer that allows users to set a target date and time, and displays the remaining time in days, hours, minutes, and seconds. The timer is fully responsive and provides a smooth user experience.

## Features

- **User-Friendly Interface**: Easily select a target date and time using a date-time picker.
- **Real-Time Countdown**: Displays the remaining time dynamically, updating every second.
- **Local Storage Support**: Saves the target date in the browser's local storage, so the countdown persists even after refreshing the page.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Customizable**: Built with CSS variables for easy theming and customization.

## Technologies Used

- **HTML5**: For the structure of the application.
- **CSS3**: For styling and responsive design.
- **JavaScript**: For dynamic functionality and real-time updates.
- **Font Awesome**: For icons used in the UI.
- **Google Fonts**: For custom typography.

## How to Use

1. Open the application in your browser.
2. Select a target date and time using the date-time picker.
3. Click the "Save" button to start the countdown.
4. The timer will display the remaining time until the selected date.
5. To change the target date, click the "Change The Target Date" button.
